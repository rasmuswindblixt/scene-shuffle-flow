# Blog Featured Images

This folder contains featured images for blog posts.

## How to Use:

1. **Add your image files** to this folder (JPG, PNG, WebP)
2. **Recommended size**: 1200x675px (16:9 aspect ratio)
3. **File naming**: Use descriptive names like `youtube-automation-guide.jpg`
4. **Reference in database**: Use `/blog-images/your-image.jpg` as the image path

## Examples:

- `/blog-images/youtube-automation-guide.jpg`
- `/blog-images/viral-video-tips.png`
- `/blog-images/content-creation-workflow.webp`

## Image Guidelines:

- **Max file size**: 500KB for fast loading
- **Format**: JPG for photos, PNG for graphics with transparency
- **Quality**: High enough for retina displays, but optimized for web
- **Aspect ratio**: 16:9 (1200x675px) works best for blog cards
